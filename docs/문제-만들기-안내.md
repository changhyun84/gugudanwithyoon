 문제 만들기 안내

엄마 아빠가 직접 문제를 넣는 방법입니다. 프로그램을 몰라도 됩니다.

> <sup>준비 중</sup> 표시가 붙은 것은 **아직 만들어지지 않은 기능**입니다. 지금 게임에는 없습니다.
> 지금 쓸 수 있는 것은 **방법 1(엑셀)** · **방법 2(메모장)** · **소원권** · **용돈** · **학습 진도** · **기록 내보내기**, 그리고 문제 켜고 끄기입니다.

## 어디에 넣나요

게임 폴더 안의 **`content/problems`** 폴더입니다. 여기에 파일을 넣으면 게임에 자동으로 나타납니다.

파일 이름이 게임에 보이는 이름이 됩니다. `3학년-나눗셈.csv`를 넣으면 게임에서 "3학년-나눗셈"으로 보입니다.

**파일을 저장하면 바로 반영됩니다.** 게임을 껐다 켤 필요 없이 아이패드에서 새로고침만 하면 됩니다.

### 과목별로 나누고 싶다면 — 폴더를 만드세요

문제가 늘어나면 **폴더로 과목을 나눌 수 있습니다.**

```
content/problems/
├─ 수학/
│   ├─ 1-1 구구단.csv
│   ├─ 1-2 2자리 곱셈.csv
│   ├─ 1-3 나눗셈.csv
│   └─ 1-4 나머지가 있는 나눗셈.csv
├─ 한국사/
│   ├─ 1-1 구석기~신석기.csv
│   └─ 1-2 청동기~철기.csv
└─ 나눗셈.csv          ← 폴더 밖에 둬도 됩니다
```

- **폴더 이름이 과목**입니다
- **파일 이름 앞의 `1-1`이 단원 번호**입니다. `1-1` `1-2` `2-1` 처럼 쓰세요. 숫자 하나만 써도 됩니다(`1 구구단.csv`)
- 폴더는 **한 겹만** 만드세요. `수학/1학기/…` 처럼 두 겹은 안 읽습니다

**지금 쓰던 파일을 옮기지 않아도 됩니다.** 폴더 밖의 파일은 지금까지처럼 그대로 나옵니다.

### 파일 이름이 겹치면 안 됩니다

다른 폴더라도 파일 이름이 같으면 하나만 읽고 나머지는 건너뜁니다. `수학/1-1.csv`와 `한국사/1-1.csv`처럼 두지 말고 `1-1 구구단.csv`, `1-1 구석기~신석기.csv` 처럼 이름을 붙여주세요.

부모 화면의 "문제 팩"에 어느 파일을 건너뛰었는지 나옵니다.

### ⚠️ 파일 이름을 바꾸면 진도가 초기화됩니다

`나눗셈.csv`를 `수학/1-3 나눗셈.csv`로 **옮기는 것은 괜찮습니다.** 폴더만 바뀌는 것이라 아이 진도가 그대로 유지됩니다.

하지만 **파일 이름 자체를 바꾸면** 게임이 새 문제로 봅니다. 아이가 그 팩에서 쌓아둔 진도와 별이 다시 0부터입니다. 이름은 처음에 정해두고 그대로 쓰세요.

## 방법 1 — 엑셀로 만들기 (CSV)

가장 편한 방법입니다. 엑셀이나 구글 스프레드시트로 이렇게 만드세요.

| 문제 | 정답 | 오답1 | 오답2 | 오답3 | 힌트 | 묶음 | 유형 |
|---|---|---|---|---|---|---|---|
| 7 × 8 | 56 | 48 | 54 | 63 | 7×4는 28. 두 배 하면? | 7단 | |
| 6 × 7 | 42 | | | | 6×3은 18. 두 배 하면? | 7단 | |
| 24 ÷ 6 | 4 | | | | 6을 몇 번 더하면 24? | 나눗셈 | |
| 사과 | apple | | | | a로 시작해 | 9월2주 | 단답 |

### 꼭 필요한 것

**문제**와 **정답** 두 칸만 있으면 됩니다. 나머지는 비워도 됩니다.

### 나머지 칸

- **오답1~3** — 비워두면 프로그램이 알아서 그럴듯한 오답을 만듭니다. 아이가 자주 하는 실수가 있다면 직접 넣어주세요. 그게 훨씬 좋은 문제가 됩니다
- **힌트** — 비우면 힌트 버튼이 안 나옵니다. 넣을 때는 **답을 알려주지 말고 방법을 알려주세요**
- **묶음** — 나중에 "나눗셈만 풀기" 같은 걸 할 때 씁니다. 비워도 됩니다
- **유형** — 답하는 방식입니다. 비우면 지금까지처럼 보기 4개 중에 고릅니다. 아래를 보세요

### 유형 — 답하는 방식 고르기

| 적는 값 | 아이가 하는 일 |
|---|---|
| (비움) 또는 `선택` | 보기 4개 중에 고릅니다 |
| `단답` | 답을 직접 씁니다 |
| `서술` | 문장으로 씁니다 |

**`단답`을 골라도 아이는 언제든 「보기 보여줘」를 눌러 4지선다로 바꿀 수 있습니다.** 막히면 누를 것이 있어야 하기 때문입니다. 힌트와 마찬가지로 눌러도 손해가 없습니다.

`단답`에서 답이 여러 개일 수 있으면 **정답 칸에 `/`로 나눠 적으세요.**

| 문제 | 정답 |
|---|---|
| 식물이 물을 빨아들이는 곳 | 뿌리/뿌리요/뿌리입니다 |
| 사과 | apple/apples |

대소문자와 앞뒤 공백, 영어 `a`/`the`는 알아서 무시합니다. 하지만 **"뿌리"와 "뿌리를"은 다른 글자로 봅니다.** 조사가 붙을 것 같으면 `/`로 같이 적어주세요. 넉넉하게 적을수록 좋습니다 — 아이가 아는데 틀린 것으로 처리되는 것이 제일 나쁩니다.

`서술`은 **정답 칸을 비워도 됩니다.** 적어두면 캐릭터가 참고합니다. 서술형은 채점하지 않고, 별도 안 나옵니다. 쓰기만 하면 풀을 받습니다. **하루에 최대 2문제만 나옵니다.**

### ⚠️ 저장할 때 주의

엑셀에서 저장할 때 파일 형식을 **"CSV UTF-8(쉼표로 분리)"** 로 고르세요. 그냥 "CSV"로 저장하면 **한글이 깨집니다.**

구글 스프레드시트는 `파일 → 다운로드 → 쉼표로 구분된 값(.csv)` 하면 됩니다. 이건 자동으로 UTF-8이라 안전합니다.

## 방법 2 — 메모장으로 만들기 (MD)

문제가 몇 개 안 되거나 엑셀 열기가 번거로울 때 씁니다. 메모장에 이렇게 쓰고 `.md`로 저장하세요.

```
# 3학년 나눗셈

묶음: 나눗셈

- 24 ÷ 6 = ?  ->  4  // 6을 몇 번 더하면 24가 될까?
- 35 ÷ 5 = ?  ->  7
- 48 ÷ 8 = ?  ->  6  // 8×6을 떠올려봐
```

규칙은 네 가지뿐입니다.

- 맨 위 `#` 줄에 이 묶음의 이름
- 문제는 `-` 로 시작
- 문제와 답 사이는 `->` (화살표 `→`도 됩니다)
- 힌트는 `//` 뒤에 (안 써도 됨)

`유형:` 줄을 넣으면 그 파일 전체에 적용됩니다.

```
# 9월 2주 영단어

묶음: 9월2주
유형: 단답

- 사과  ->  apple
- 학교  ->  school
```

메모장에서 저장할 때 인코딩을 **UTF-8**로 고르세요.

MD 방식에서는 오답 보기를 직접 지정할 수 없고 항상 자동으로 만들어집니다.

## 방법 3 — 영어 단어를 사진으로 등록하기 <sup>준비 중</sup>

영어 단어는 매주 새로 나오는데, 매번 손으로 치면 몇 주 못 갑니다. 단어장이나 시험지를 찍으면 표로 만들어 줍니다.

### 하는 법

1. **부모 폰**에서 `/parent` 주소로 들어갑니다 (PC와 같은 Wi-Fi여야 합니다)
2. `사진으로 단어 넣기`를 누르고 단어장 페이지를 찍습니다
3. 잠시 뒤 **단어와 뜻이 표로** 뜹니다
4. **표를 하나씩 확인하고 고칩니다** ← 가장 중요합니다
5. 파일 이름을 정하고 `저장`을 누르면 새 문제 팩이 생깁니다

### 반드시 확인하고 저장하세요

프로그램이 글자를 잘못 읽는 일이 있습니다. `purpose`를 `porpose`로 읽었다면, 아이는 **맞게 쓰고 틀렸다는 결과**를 받습니다. 이 게임에서 절대 일어나면 안 되는 일입니다.

읽기 애매한 칸은 **표시가 되어 있습니다.** 그 칸부터 보세요.

확인 없이 바로 저장되는 길은 만들어 두지 않았습니다. 번거롭더라도 한 번씩 훑어주세요.

### 찍을 때

- 밝은 곳에서, 종이를 평평하게
- 한 장에 20~30개 정도. 페이지를 나눠서 여러 번 찍는 편이 정확합니다
- **한 번 찍은 한 장이 한 묶음**이 됩니다. 오답 보기가 같은 묶음 안에서 나오기 때문에, 한 주 분량을 한 파일로 두면 보기가 자연스럽습니다

### 방향 고르기

같은 단어로 세 가지 문제를 만들 수 있습니다.

| | 문제 | 답 |
|---|---|---|
| 영 → 한 | `apple` | 사과 (보기에서 고름) |
| 한 → 영 | 사과 | `apple` (보기에서 고름) |
| 철자 쓰기 | 사과 | `apple` (직접 씀) |

**처음에는 영 → 한만 켜두는 것을 권합니다.** 아이가 익숙해지면 부모 화면에서 나머지를 켜세요. 아이 입장에서는 새 문제가 열린 사건이 됩니다.

> 이 기능은 아래 **AI 도우미**를 켜야 씁니다. 켜지 않아도 엑셀로 직접 만드는 길은 그대로 있습니다.

## AI 도우미 켜기 <sup>준비 중</sup>

두 가지 일에만 씁니다.

- 사진에서 단어 뽑기 (방법 3)
- **선생님이 되어** 서술형 답에 한마디 하고 조언해주기

**기본은 꺼져 있습니다.** Google AI Studio에서 무료 API 키를 발급받아 부모 화면 설정에 넣으면 켜집니다.

### 선생님이 누구인가요

서술형을 풀 때만 나오는 캐릭터입니다. 목장의 친구들(양·고양이·토끼·코알라·카피바라)과 **역할이 다릅니다.**

| | 친구들 | 선생님 |
|---|---|---|
| 하는 말 | "나도 이거 자꾸 헷갈리더라" | "이건 이래서 그런 거야" |
| 주는 것 | 안심 | 배움 |
| 어디 있나 | 목장, 문제 풀 때 | 서술형을 쓸 때만 |
| 꾸미기 | 모자·목도리 | 없음 |

**둘 다 필요합니다.** 친구들이 "어른도 헷갈린다"를 보여주는 것이 이 게임이 통한 이유이고, 선생님은 그 위에 배움을 얹습니다. 그래서 섞지 않고 따로 둡니다.

이름은 아이가 지어줄 수 있습니다.

### 조언 스위치

부모 화면에 스위치가 하나 있습니다. **기본은 켜짐**입니다.

| | 선생님이 하는 말 |
|---|---|
| **조언 켜짐** | 잘 쓴 부분을 짚어주고 → 다음에 해볼 것을 **하나** 알려줍니다 |
| 조언 꺼짐 | 잘 쓴 부분만 짚어줍니다 |
| AI 꺼짐 | 미리 준비된 말을 합니다 |

**세 경우 다 아이 눈에는 같은 선생님입니다.** 말이 조금 짧아질 뿐, 화면이 바뀌거나 없어지는 것이 없습니다.

### 언제 조언을 꺼야 하나요

**아이가 쓰는 글이 짧아지면** 끄세요. 그게 제일 먼저 나타나는 신호입니다.

선생님 말이 아이에게 지적으로 읽히기 시작하면, 아이는 지적받을 거리를 줄이려고 짧게 씁니다. 서술형을 아예 피하기 시작하면 그때는 이미 늦은 편입니다.

끄는 순서는 이렇습니다.

```
1. 조언 스위치 끄기       ← 여기서 대부분 해결됩니다
2. AI 끄기
3. 서술형 자체를 끄기
```

### 선생님이 하지 않는 것

- 점수를 매기거나 몇 점이라고 말하지 않습니다
- "부족해요", "아쉽네요" 같은 말을 하지 않습니다
- 맞춤법이나 띄어쓰기를 고쳐주지 않습니다 — 고치기 시작하면 **아이가 쓰는 양이 줄어듭니다**
- 다시 써 보라고 하지 않습니다
- 틀린 부분을 여러 개 늘어놓지 않습니다. 조언은 **한 번에 하나**입니다
- 어제와 비교하거나 다른 아이와 비교하지 않습니다
- 아이가 한 줄만 써도 실망하지 않습니다
- 아이와 아무 말이나 주고받는 창구는 없습니다. **지금 푸는 문제에 대해서만** 말합니다

### 한 달에 한 번, 선생님 말을 읽어보세요

부모 화면에 **선생님이 한 조언만 모아 놓은 목록**이 있습니다. 한 주에 열 줄쯤이라 훑는 데 1분이면 됩니다.

프로그램이 금지어를 걸러내기는 하지만, 그 그물을 빠져나가는 어색한 말은 사람이 읽어야 보입니다. 읽어보고 마음에 안 들면 조언 스위치를 끄면 됩니다.

### 데이터 전송

아이가 쓴 글이 Google 서버로 전송됩니다. 무료 등급은 보낸 내용이 서비스 개선에 쓰일 수 있습니다.

**아이 이름은 보내지 않습니다.** 문제와 아이가 쓴 답만 나갑니다. 주고받은 내용은 전부 부모 화면에서 볼 수 있고, 하루 사용 횟수에 상한이 있습니다.

### 안 켜도 됩니다

**언제든 끌 수 있고, 꺼도 게임은 그대로 돕니다.** 서술형도 AI 없이 동작합니다 — 선생님이 미리 준비된 말을 할 뿐입니다.

인터넷이 끊기거나 크레딧이 떨어져도 **아이 화면에는 아무 변화가 없습니다.** 아이는 모릅니다.

준비된 말은 `content/messages.csv`에서 직접 고칠 수 있습니다. 캐릭터 칸에 `선생님`, 상황 칸에 `글쓰기`라고 적으세요.

## 좋은 문제를 만드는 요령

**한 파일에 20~40개.** 너무 많으면 아이가 한 바퀴 도는 데 오래 걸려서 진도감이 안 납니다.

**쉬운 것부터 순서대로.** 게임은 파일 순서대로 앞에서 세 문제씩만 열어줍니다. 어려운 걸 위에 두면 처음부터 막힙니다.

**힌트는 '방법'을 알려주세요.** 
- ❌ `답은 56이야`
- ⭕ `7×4는 28. 그걸 두 배 하면 돼`

**한 문제는 한 가지만 물어보세요.** 여러 단계를 거쳐야 하는 문제는 4지선다에 안 맞습니다.

**오답 보기를 직접 넣을 거라면**, 아이가 실제로 헷갈리는 값으로 하세요. 7×8의 좋은 오답은 49(7×7)나 63(7×9)이지 100 같은 게 아닙니다.

**캐릭터**: `양` `고양이` `토끼` `코알라` `카피바라` `공통` `선생님`<sup>준비 중</sup>

메시지 안에 `{이름}`을 쓰면 아이 이름이, `{정답}`을 쓰면 그 문제의 답이 들어갑니다.

집안 농담이나 아이만 아는 표현을 넣으면 반응이 훨씬 좋습니다.

### 메시지 쓸 때 지켜주실 것

이 게임은 **틀리는 걸 부끄러워하는 아이**를 위해 만들었습니다. 다음 세 가지만 지켜주세요.

**1. 빠르다고 칭찬하지 마세요.**
"우와 빠르다!"는 다음에 느릴 때 부담이 됩니다. "우와 대단해!"로 충분합니다.

**2. 틀렸을 때 위로하지 마세요.**
"괜찮아, 다음엔 잘할 거야"는 아이에게 *방금 못했다*는 걸 확인시킵니다. 그냥 태연하게 넘어가는 게 낫습니다.
- ❌ `아쉽다! 조금만 더 힘내자`
- ⭕ `아, {정답}이래. 나도 이거 자꾸 헷갈리더라`

**3. 캐릭터도 헷갈린다고 자주 말하게 하세요.**
어른도, 캐릭터도 헷갈린다는 걸 반복해서 보는 것이 이 게임에서 가장 중요한 학습입니다.

**4. 친구들을 선생님처럼 만들지 마세요.** <sup>준비 중</sup>
양·고양이·토끼·코알라·카피바라는 **같이 헷갈리는 친구**입니다. 가르치는 말투로 쓰기 시작하면 위 3번이 사라집니다. 가르치는 역할은 `선생님`에게만 주세요.

## 소원권 만들기

아이가 별을 모아 **진짜 소원**으로 바꿉니다. 아이스크림, 늦게 자기, 저녁 메뉴 정하기 같은 것입니다.

`content` 폴더에 **`wishes.csv`** 를 만드세요. 엑셀로 이렇게 씁니다.

| 소원 | 별 | 설명 |
|---|---|---|
| 아이스크림 사러 가기 | 8 | 아무 때나 쓸 수 있어 |
| 오늘은 30분 늦게 자기 | 10 | |
| 같이 영화 보기 | 20 | 팝콘도 같이 |

**소원**과 **별** 두 칸만 있으면 됩니다. 설명은 비워도 됩니다. 저장할 때 **"CSV UTF-8"** 로 하는 것은 문제 파일과 같습니다.

**이 파일이 없으면 소원권 기능은 아이 화면에 아예 안 나타납니다.** 쓰기 싫으면 안 만들면 됩니다.

### 아이가 바꾸면

아이 화면에 소원권이 쌓이고, **아이가 그 화면을 보여주러 옵니다.** 그게 이 기능의 전부입니다.

부모 화면(`/parent`)의 **소원권**에도 무엇을 언제 몇 번 바꿔갔는지 나옵니다. 아이가 깜빡해도 알 수 있습니다.

**받은 소원권은 목록에서 지워지지 않습니다.** 들어주신 뒤에도 기념처럼 남습니다. 아이가 실수로 지울 일이 없게 하려는 것입니다.

### 값을 정할 때

별은 **문제를 완전히 외울 때마다 하나씩** 생깁니다. 하루에 0~3개쯤입니다.

- 8~12별 — 일주일에 한 번쯤 (아이스크림, 늦게 자기)
- 20~30별 — 한 달에 한 번쯤 (영화, 나들이)

**값을 올리지 마세요.** 10별짜리를 모으던 아이에게 15로 오르면 손해입니다. 비싸게 하고 싶으면 새 줄을 추가하세요.

집에서 실제로 해줄 수 있는 것만 적으세요. 못 들어줄 소원이 목록에 있으면 그게 제일 나쁩니다.

## 용돈 켜기

아이가 **풀 🌿**을 진짜 돈으로 바꿉니다. 부모 화면(`/parent`)의 **용돈**에서 켭니다. **기본은 꺼져 있습니다.**

| 정하는 것 | 기본값 |
|---|---|
| 환율 | 풀 100개 = 200원 |
| 바꾸는 날 | 토요일 |
| 한 번에 최대 | 500풀 |

기본값이면 **주 1,000원**입니다. 아이가 하루 20문제를 풀면 풀이 약 100개 쌓이니, 한 주에 약 700개입니다.

### 왜 별이 아니라 풀인가요

별은 **문제를 완전히 외웠을 때만** 나옵니다. 용돈을 별로 바꾸게 하면 *틀리면 돈을 못 버는* 구조가 됩니다.

풀은 **풀기만 해도** 쌓입니다. 틀려도 용돈이 나옵니다. 이 게임이 통한 이유가 바로 그것이라, 여기서 뒤집으면 안 됩니다.

### 왜 주 1회인가요

매일 바꿀 수 있으면 **놀이가 일이 됩니다.** 요일을 정해두면 그날이 작은 사건이 되고 나머지 엿새는 그냥 노는 날입니다.

**한 번에 바꿀 수 있는 양에도 상한이 있습니다.** 상한이 없으면 모은 풀을 전부 돈으로 바꿔서, 가게에 사고 싶은 게 있어도 못 삽니다.

### 아이가 바꾸면

소원권과 같습니다. 아이 화면에 기록이 남고 **아이가 보여주러 옵니다.** 부모 화면에도 날짜·금액·합계가 나옵니다.

**바꾼 기록은 지워지지 않습니다.**

## 문제를 잠깐 안 나오게 하고 싶을 때

**파일에서 지우지 마세요.** 지우면 아이가 그 문제에 쌓아둔 진도까지 같이 사라집니다.

부모 화면(`/parent`)의 **문제 켜고 끄기**에서 체크를 풀고 저장하세요. 아이패드에서 새로고침하면
그 문제는 더 이상 안 나옵니다. 진도는 그대로 남아 있어서 언제든 다시 켤 수 있고,
**이미 받은 별과 스티커, 해금한 친구들도 그대로입니다.**

이럴 때 쓰면 좋습니다.

- 아직 학교에서 안 배운 단원
- 문제를 잘못 적어서 고칠 때까지 빼두고 싶을 때
- 팩 하나를 통째로 다음 학기로 미룰 때

한 팩에서 너무 많이 끄면 **같은 문제가 자주 반복됩니다.** 8개 미만이 되면 화면이 알려줍니다.

## 기록 지키기 — 꼭 한 번 해두세요

아이가 몇 주 모은 **별·아이템·도감은 다시 만들 수 없습니다.** 두 가지만 해두시면 됩니다.

### 1. 아이패드 홈 화면에 추가하기

아이패드 사파리에서 게임을 연 뒤, 위쪽 **공유 버튼 → 홈 화면에 추가**를 누르세요.

- 아이콘을 누르면 주소창 없이 앱처럼 열립니다
- **더 중요한 이유**: 사파리는 일주일 넘게 안 들어간 사이트의 저장 내용을 지웁니다. 홈 화면에 추가해두면 그 대상에서 빠집니다

아이 화면에도 안내가 한 번 뜹니다. 아이가 "알겠어"를 누르면 다시 안 나옵니다.

### 2. 가끔 기록 내보내기

부모 화면(`/parent`)의 **기록 내보내기 · 되돌리기**에서 `지금 기록 내보내기`를 누르면 파일이 하나 받아집니다. 메일로 보내두거나 클라우드에 올려두세요.

**한 달에 한 번이면 충분합니다.** 아이가 큰 걸 샀거나 친구를 새로 만난 날에 한 번 더 눌러두면 좋습니다.

### 되돌릴 때

같은 화면에서 파일을 고르면 **지금 기록과 나란히** 보여줍니다.

| | 지금 | 되돌리면 |
|---|---|---|
| 별 | 11 | 3 |
| 완전히 외운 것 | 18 | 5 |

줄어드는 값은 눈에 띄게 표시됩니다. 확인하고 누르세요.

> ⚠️ **되돌리기는 덮어쓰기입니다.** 지금 기록은 사라집니다.
> 되돌리기 전에 `지금 기록 내보내기`를 한 번 눌러두면 언제든 다시 돌아올 수 있습니다.

파일이 안 될 때는 텍스트를 복사해서 붙여넣어도 됩니다.

## 잘 안 될 때

**게임에 새 문제가 안 보여요**
아이패드에서 새로고침하세요. 그래도 안 보이면 부모 화면(`/parent`)의 "문제 팩" 목록을 여세요. 파일을 못 읽었으면 이유가 적혀 있습니다.

**한글이 □□□로 나와요**
파일을 UTF-8로 다시 저장하세요. 엑셀이라면 "CSV UTF-8"입니다.

**문제 몇 개만 빠졌어요**
부모 화면에 몇 번째 줄이 왜 빠졌는지 나옵니다. 대부분 정답 칸이 비었거나 `->`가 빠진 경우입니다.

**문제 내용을 고쳤더니 진도가 초기화됐어요**
정상입니다. 문제 글자가 바뀌면 새 문제로 봅니다. 오타 수정도 마찬가지이니, 이미 아이가 풀고 있는 문제는 되도록 건드리지 마세요. 힌트나 오답 보기만 고치는 건 진도에 영향이 없습니다.

**아이패드에서 주소가 안 열려요**
- PC와 아이패드가 같은 Wi-Fi인지 (게스트 네트워크는 안 됩니다)
- PC에서 게임 창이 켜져 있는지
- 처음 켤 때 방화벽 창이 떴다면 "허용"을 눌렀는지
- PC를 껐다 켜면 주소의 숫자가 바뀔 수 있습니다. 게임 창에 나오는 주소를 다시 확인하세요
