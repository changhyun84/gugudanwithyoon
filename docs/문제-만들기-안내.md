# 문제 만들기 안내

엄마 아빠가 직접 문제를 넣는 방법입니다. 프로그램을 몰라도 됩니다.

---

## 어디에 넣나요

게임 폴더 안의 **`content/problems`** 폴더입니다. 여기에 파일을 넣으면 게임에 자동으로 나타납니다.

파일 이름이 게임에 보이는 이름이 됩니다. `3학년-나눗셈.csv`를 넣으면 게임에서 "3학년-나눗셈"으로 보입니다.

**파일을 저장하면 바로 반영됩니다.** 게임을 껐다 켤 필요 없이 아이패드에서 새로고침만 하면 됩니다.

---

## 방법 1 — 엑셀로 만들기 (CSV)

가장 편한 방법입니다. 엑셀이나 구글 스프레드시트로 이렇게 만드세요.

| 문제 | 정답 | 오답1 | 오답2 | 오답3 | 힌트 | 묶음 |
|---|---|---|---|---|---|---|
| 7 × 8 | 56 | 48 | 54 | 63 | 7×4는 28. 두 배 하면? | 7단 |
| 6 × 7 | 42 | | | | 6×3은 18. 두 배 하면? | 7단 |
| 24 ÷ 6 | 4 | | | | 6을 몇 번 더하면 24? | 나눗셈 |

### 꼭 필요한 것

**문제**와 **정답** 두 칸만 있으면 됩니다. 나머지는 비워도 됩니다.

### 나머지 칸

- **오답1~3** — 비워두면 프로그램이 알아서 그럴듯한 오답을 만듭니다. 아이가 자주 하는 실수가 있다면 직접 넣어주세요. 그게 훨씬 좋은 문제가 됩니다
- **힌트** — 비우면 힌트 버튼이 안 나옵니다. 넣을 때는 **답을 알려주지 말고 방법을 알려주세요**
- **묶음** — 나중에 "나눗셈만 풀기" 같은 걸 할 때 씁니다. 비워도 됩니다

### ⚠️ 저장할 때 주의

엑셀에서 저장할 때 파일 형식을 **"CSV UTF-8(쉼표로 분리)"** 로 고르세요. 그냥 "CSV"로 저장하면 **한글이 깨집니다.**

구글 스프레드시트는 `파일 → 다운로드 → 쉼표로 구분된 값(.csv)` 하면 됩니다. 이건 자동으로 UTF-8이라 안전합니다.

## 방법 2 — 메모장으로 만들기 (MD)

문제가 몇 개 안 되거나 엑셀 열기가 번거로울 때 씁니다. 메모장에 이렇게 쓰고 `.md`로 저장하세요.

```
# 3학년 나눗셈

묶음: 나눗셈

- 24 ÷ 6 = ?  ->  4  // 6을 몇 번 더하면 24가 될까?
- 35 ÷ 5 = ?  ->  7
- 48 ÷ 8 = ?  ->  6  // 8×6을 떠올려봐
```

규칙은 네 가지뿐입니다.

- 맨 위 `#` 줄에 이 묶음의 이름
- 문제는 `-` 로 시작
- 문제와 답 사이는 `->` (화살표 `→`도 됩니다)
- 힌트는 `//` 뒤에 (안 써도 됨)

메모장에서 저장할 때 인코딩을 **UTF-8**로 고르세요.

MD 방식에서는 오답 보기를 직접 지정할 수 없고 항상 자동으로 만들어집니다.

---

## 좋은 문제를 만드는 요령

**한 파일에 20~40개.** 너무 많으면 아이가 한 바퀴 도는 데 오래 걸려서 진도감이 안 납니다.

**쉬운 것부터 순서대로.** 게임은 파일 순서대로 앞에서 세 문제씩만 열어줍니다. 어려운 걸 위에 두면 처음부터 막힙니다.

**힌트는 '방법'을 알려주세요.** 
- ❌ `답은 56이야`
- ⭕ `7×4는 28. 그걸 두 배 하면 돼`

**한 문제는 한 가지만 물어보세요.** 여러 단계를 거쳐야 하는 문제는 4지선다에 안 맞습니다.

**오답 보기를 직접 넣을 거라면**, 아이가 실제로 헷갈리는 값으로 하세요. 7×8의 좋은 오답은 49(7×7)나 63(7×9)이지 100 같은 게 아닙니다.

## 응원 메시지 바꾸기

`content/messages.csv` 파일입니다. 캐릭터가 하는 말을 직접 추가하거나 고칠 수 있습니다.

| 캐릭터 | 상황 | 메시지 |
|---|---|---|
| 양 | 정답 | 맞았어! 잘하고 있어. |
| 고양이 | 정답 | …뭐, 나쁘지 않네. |
| 토끼 | 힌트정답 | 힌트 잘 썼다! 그거 똑똑한 방법이야. |
| 카피바라 | 오답 | 아 그렇구나~ {정답}이래. 뭐 그럴 수도 있지~ |

**캐릭터**: `양` `고양이` `토끼` `코알라` `카피바라` `공통`
**상황**: `정답` `힌트정답` `오답` `시작` `끝` `새아이템` `오랜만` `마스터`

메시지 안에 `{이름}`을 쓰면 아이 이름이, `{정답}`을 쓰면 그 문제의 답이 들어갑니다.

집안 농담이나 아이만 아는 표현을 넣으면 반응이 훨씬 좋습니다.

### 메시지 쓸 때 지켜주실 것

이 게임은 **틀리는 걸 부끄러워하는 아이**를 위해 만들었습니다. 다음 세 가지만 지켜주세요.

**1. 빠르다고 칭찬하지 마세요.**
"우와 빠르다!"는 다음에 느릴 때 부담이 됩니다. "우와 대단해!"로 충분합니다.

**2. 틀렸을 때 위로하지 마세요.**
"괜찮아, 다음엔 잘할 거야"는 아이에게 *방금 못했다*는 걸 확인시킵니다. 그냥 태연하게 넘어가는 게 낫습니다.
- ❌ `아쉽다! 조금만 더 힘내자`
- ⭕ `아, {정답}이래. 나도 이거 자꾸 헷갈리더라`

**3. 캐릭터도 헷갈린다고 자주 말하게 하세요.**
어른도, 캐릭터도 헷갈린다는 걸 반복해서 보는 것이 이 게임에서 가장 중요한 학습입니다.

## 문제를 잠깐 안 나오게 하고 싶을 때

**파일에서 지우지 마세요.** 지우면 아이가 그 문제에 쌓아둔 진도까지 같이 사라집니다.

부모 화면(`/parent`)의 **문제 켜고 끄기**에서 체크를 풀고 저장하세요. 아이패드에서 새로고침하면
그 문제는 더 이상 안 나옵니다. 진도는 그대로 남아 있어서 언제든 다시 켤 수 있고,
**이미 받은 별과 스티커, 해금한 친구들도 그대로입니다.**

이럴 때 쓰면 좋습니다.

- 아직 학교에서 안 배운 단원
- 문제를 잘못 적어서 고칠 때까지 빼두고 싶을 때
- 팩 하나를 통째로 다음 학기로 미룰 때

한 팩에서 너무 많이 끄면 **같은 문제가 자주 반복됩니다.** 8개 미만이 되면 화면이 알려줍니다.

## 요즘 어려워하는 문제 보기

부모 화면 맨 위에 최근 7일 동안 아이가 어려워한 문제가 최대 5개 나옵니다.

**이 목록을 보고 아이에게 직접 묻지 마세요.** 약한 문제는 게임이 알아서 며칠 뒤에 다시 냅니다.
어른이 물어보는 순간, 이 게임을 만든 이유가 사라집니다.

대신 **문제 파일을 고치세요.**

- 힌트가 없다고 나오면 → 그 문제에 힌트를 넣어주세요
- 힌트가 이미 있으면 → 그냥 두세요. 정상입니다

며칠 놀아야 목록이 채워집니다. 처음에 비어 있는 것은 정상입니다.

## 잘 안 될 때

**게임에 새 문제가 안 보여요**
아이패드에서 새로고침하세요. 그래도 안 보이면 부모 화면(`/parent`)의 "문제 팩" 목록을 여세요. 파일을 못 읽었으면 이유가 적혀 있습니다.

**한글이 □□□로 나와요**
파일을 UTF-8로 다시 저장하세요. 엑셀이라면 "CSV UTF-8"입니다.

**문제 몇 개만 빠졌어요**
부모 화면에 몇 번째 줄이 왜 빠졌는지 나옵니다. 대부분 정답 칸이 비었거나 `->`가 빠진 경우입니다.

**문제 내용을 고쳤더니 진도가 초기화됐어요**
정상입니다. 문제 글자가 바뀌면 새 문제로 봅니다. 오타 수정도 마찬가지이니, 이미 아이가 풀고 있는 문제는 되도록 건드리지 마세요. 힌트나 오답 보기만 고치는 건 진도에 영향이 없습니다.

**아이패드에서 주소가 안 열려요**
- PC와 아이패드가 같은 Wi-Fi인지 (게스트 네트워크는 안 됩니다)
- PC에서 게임 창이 켜져 있는지
- 처음 켤 때 방화벽 창이 떴다면 "허용"을 눌렀는지
- PC를 껐다 켜면 주소의 숫자가 바뀔 수 있습니다. 게임 창에 나오는 주소를 다시 확인하세요
