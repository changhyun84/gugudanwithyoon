# 양이랑 구구단 v2

가정용 학습 게임입니다. 초등 3학년 아이 한 명을 위해 만들었고, 집 PC에서 띄워 아이패드로 접속해 사용합니다.
**v2는 1~4단계까지 완성되어 실사용 중입니다.**

---

## 새 대화에서 이어받는 분께

아래 순서로 읽으세요.

| 순서 | 문서 | 내용 |
|---|---|---|
| 1 | `기획서.md` | 배경, **절대 원칙(가장 중요)**, 기능 정의, 보상 경제 |
| 2 | `구현-현황.md` | **지금까지 만든 것과 설계서에서 바뀐 결정** |
| 3 | `기술설계서.md` | 아키텍처, API, 스키마, 파일 포맷, 구현 순서 |
| 4 | `문제-만들기-안내.md` | 부모가 문제를 등록하는 방법 (사용자 매뉴얼) |
| 5 | `설치-실행-안내.md` | 부모가 설치·실행하는 방법 (사용자 매뉴얼) |

`기획서.md`의 **2장 "절대 원칙"은 협상 대상이 아닙니다.** 이 아이는 틀리는 것을 부끄러워해서 어른 앞에서 구구단 묻기를 거부했던 아이입니다. 게임이 성공한 이유는 재미가 아니라 *아무도 안 보고, 틀려도 손해가 없어서*입니다. 재미나 학습 효율을 이유로 원칙을 깎지 마세요.

`기술설계서.md`와 `구현-현황.md`가 어긋나면 **`구현-현황.md`가 최신**입니다. 바뀐 이유가 각각 적혀 있습니다.

## 지금 상태

**완료** — 서버 뼈대 / v1 이식 / 문제 팩 / 캐릭터 5종 + 응원 메시지
**다음** — 5단계 보상 확장 (도감, 상점 단계 개방, 배경)

- Python 표준 라이브러리만 사용. 외부 패키지 없음
- 데이터는 `data\profiles\*.json`. DB 없음. 원자적 저장 + 하루 1회 자동 백업(30일)
- 문제는 `content\problems\*.csv|md`. 저장하면 새로고침만으로 반영
- 캐릭터 5종(양·고양이·토끼·코알라·카피바라)은 별로 해금. 아이템은 앵커 방식으로 공용

```
server.py     HTTP + 프로필 저장
packs.py      CSV/MD 파서
web/          app.js · engine.js · characters.js · styles.css · index.html · parent.html
content/      problems/*.csv|md · messages.csv
data/         자동 생성, git 제외
```

```
시작하기.bat 더블클릭  →  검은 창의 주소를 아이패드 Safari에 입력
```

부모 화면은 주소 뒤에 `/parent` (PIN 기본 0000).
자세한 것은 `설치-실행-안내.md`, GitHub 연동은 `깃허브-연결.md`.

## 판단이 필요할 때

- **원칙과 재미가 부딪히면** → 원칙
- **문서에 없는 세부사항** → 기획서 2장 원칙에 비추어 판단하고, 결정한 내용을 `구현-현황.md`에 추가
- **아이가 요청한 것 vs 원칙** → 요청의 *의도*를 살리되 원칙을 지키는 형태로 변형 (스피드 모드 처리 방식이 그 예시)
- **보상 규칙을 건드릴 때** → 반드시 60일 시뮬레이션 먼저 (`구현-현황.md` 6장)

## 작업 방식

각 단계가 끝날 때마다 **실제로 돌아가는 상태**여야 합니다. 화면을 만들면 브라우저 없이도 검증할 수 있습니다 — `jsdom`으로 `app.js`를 그대로 import해 버튼을 클릭시키는 방법이 `구현-현황.md` 6장에 있습니다. 이 방식으로 별 조기 고갈, 조사 오류, 캐릭터 발견 경로 누락을 실제로 잡았습니다.

`app.js`를 일괄 치환으로 수정할 때는 **치환 대상이 파일에 정확히 한 번만 있는지 확인**하세요. 한 번 범위를 잘못 잡아 파일이 깨진 적이 있습니다.
