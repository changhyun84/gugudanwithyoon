# 깃허브에 올려서 친구들도 하게 하기

인터넷 주소 하나로 아이 친구들도 같은 게임을 할 수 있게 만드는 방법입니다.
**컴퓨터를 켜두지 않아도 되고, 돈도 들지 않습니다.**

먼저 알아둘 것 하나 — 올라가는 것은 **게임과 문제뿐**입니다.
아이가 푼 기록·별·스티커는 **각자 자기 아이패드 안에만** 남습니다. 서버에 아무것도 안 올라갑니다.
그래서 다른 집 아이가 우리 아이 기록을 볼 수 없고, 우리도 그 집 기록을 갖고 있지 않습니다.

---

## 0. 올리기 전에 딱 두 가지만 확인

### 저장소가 공개(Public)됩니다

무료 계정에서 GitHub Pages를 쓰려면 저장소가 공개여야 합니다. **인터넷의 누구나 파일을 볼 수 있다**는 뜻입니다.

| | 올라가나요 |
|---|---|
| 아이가 푼 기록, 별, 스티커, 산 물건 | **안 올라갑니다** (`data/` 폴더는 제외돼 있습니다) |
| 문제 파일 (`content/problems`) | 올라갑니다 |
| 응원 메시지 (`content/messages.csv`) | 올라갑니다 |
| 소원권 (`content/wishes.csv`) | 올라갑니다 |
| 부모 화면 PIN | 올라갑니다 (기본 0000) |

그래서 **올리기 전에 `content` 폴더를 한 번 읽어보세요.** 아이 이름, 집안 농담, 가족 얘기가 들어 있으면 지금 고치는 게 낫습니다. 소원권의 "저녁 메뉴 내가 정하기" 같은 것은 남이 봐도 괜찮지만, "할머니 댁 가기" 같은 건 생각보다 개인적입니다.

정 걸리면 `.gitignore` 파일 맨 아래의 `# content/` 에서 `#` 을 지우세요. 그러면 문제 파일이 안 올라갑니다 — 대신 **친구들은 문제가 하나도 없는 게임**을 받게 됩니다. 구구단만 나옵니다.

### 부모 화면은 잠기지 않습니다

주소 뒤에 `parent.html` 을 붙이면 누구나 부모 화면에 들어갈 수 있습니다. PIN이 있지만 기본값이 0000이고, 그 값도 파일에 그대로 보입니다.

그래도 괜찮은 이유는 **그 화면이 자기 브라우저의 기록만 건드리기 때문**입니다. 남의 아이 기록에는 손이 닿지 않습니다. 친구 집 부모가 그 집 진도를 정하는 것이 원래 의도입니다.

---

## 1. 저장소에 올리기 (한 번)

컴퓨터에서 게임 폴더를 열고, 검은 창(터미널)에 한 줄:

```
git push
```

처음이라 물어보면 GitHub 아이디와 비밀번호(또는 토큰)를 넣습니다.

`git push` 가 안 되면 아직 저장소가 연결되지 않은 것입니다. 브라우저에서 <https://github.com/new> 로 새 저장소를 만든 뒤, 화면에 나오는 안내 두 줄을 그대로 붙여넣으면 됩니다.

## 2. 저장소를 공개로 바꾸기 (한 번)

1. GitHub에서 저장소를 엽니다
2. 위쪽 **Settings**
3. 맨 아래 **Danger Zone** → **Change repository visibility** → **Make public**
4. 저장소 이름을 그대로 한 번 더 입력하면 바뀝니다

## 3. Pages 켜기 (한 번)

1. 같은 **Settings** 화면, 왼쪽 목록에서 **Pages**
2. **Source** 를 `Deploy from a branch` 에서 **`GitHub Actions`** 로 바꿉니다
3. 끝입니다. 저장 버튼도 없습니다

> **이 3번을 안 하면 아무리 올려도 주소가 안 생깁니다.** 가장 많이 빠뜨리는 단계입니다.

## 4. 만들어지는 것 보기

1. 저장소 위쪽 **Actions** 탭
2. `GitHub Pages` 라는 줄이 노란 점(돌아가는 중)에서 **초록 체크**로 바뀌면 끝입니다. 2~4분 걸립니다
3. 빨간 X가 뜨면 → 아래 "빨간 X가 떴을 때"

## 5. 주소

```
아이 화면    https://changhyun84.github.io/gugudanwithyoon/
부모 화면    https://changhyun84.github.io/gugudanwithyoon/parent.html
```

아이패드에서 열고 **공유 버튼 → 홈 화면에 추가** 를 꼭 해주세요.
이건 예쁘라고 하는 게 아닙니다 — **아이폰·아이패드 사파리는 일주일 안 들어가면 저장된 기록을 지웁니다.** 홈 화면에 추가한 것은 지우지 않습니다. 친구들에게 주소를 줄 때 이 한 줄을 같이 보내주세요.

---

## ⚠️ 가장 많이 오해하는 것 — 기록은 **브라우저 안**에 있습니다

와이파이와 **아무 상관이 없습니다.**

```js
// 정적 배포에서 아이 기록을 읽는 코드
return readLocal(id);   // ← 이 브라우저의 localStorage
```

| 상황 | 아이 기록이 보이나 |
|---|---|
| 노트북 크롬에서 풀고 → **같은 노트북 크롬**으로 `parent.html` | **보입니다** |
| 노트북 크롬에서 풀고 → **엄마 아이폰** (같은 와이파이) | **안 보입니다** |
| 노트북 크롬에서 풀고 → 같은 노트북의 **엣지·사파리** | **안 보입니다** |
| 노트북 크롬에서 풀고 → 밖에서 **같은 노트북 크롬** | **보입니다** |
| 아이가 노트북과 아이패드를 번갈아 씀 | **기록이 둘로 갈라집니다** |

기준은 *같은 와이파이*가 아니라 **같은 브라우저**입니다.

### 그래서 부모 화면은 아이 기기에서 여세요

주소 뒤에 `parent.html`을 붙이면 됩니다. 아이 화면에는 그리로 가는 버튼이 없으니(원칙 2.7) 부모가 주소를 치면 됩니다.

### 엄마 폰으로 컨트롤하고 싶다면 — 집 서버를 쓰세요

`시작하기.bat`으로 여는 방식은 기록을 **집 PC의 파일**에 남깁니다. 그래서 같은 와이파이 안의 **모든 기기가 같은 기록**을 봅니다.

| | 집 서버 (`시작하기.bat`) | GitHub Pages |
|---|---|---|
| 기록이 있는 곳 | 집 PC의 `data/profiles/*.json` | 각 브라우저 |
| 기기 여러 대가 **같은 기록** | **됩니다** (같은 와이파이) | 안 됩니다 |
| 엄마 폰으로 부모 화면 | **됩니다** | 안 됩니다 |
| 아이가 노트북·아이패드 번갈아 | **됩니다** | 갈라집니다 |
| 자동 백업 (하루 1회, 30일) | **있습니다** | 없습니다 |
| 집 PC를 켜둬야 함 | 예 | 아니요 |

**우리 집은 집 서버, 친구들은 Pages** 를 권합니다. 둘을 섞어 쓰면 기록이 따로 노니, 옮길 때는 부모 화면의 **기록 내보내기 → 되돌리기**를 쓰세요.

## 그 다음부터는 자동입니다

문제를 고치거나 새로 넣고 `git push` 하면, 3~4분 뒤에 주소에 그대로 반영됩니다. 3번까지 한 번 해두면 다시 할 일이 없습니다.

컴퓨터 없이 **브라우저에서 바로 문제를 넣는 방법**은 `문제-만들기-안내.md` 의 "인터넷에 올린 뒤에는" 을 보세요. 엄마가 혼자 할 수 있게 써뒀습니다.

## 빨간 X가 떴을 때

Actions에서 실패한 줄을 누르면 어디서 멈췄는지 나옵니다.

| 멈춘 곳 | 뜻 | 할 일 |
|---|---|---|
| **검사** | 문제 파일이나 코드가 깨졌습니다 | 빨간 글씨에 파일 이름이 나옵니다. 그 파일을 되돌리세요 |
| **빌드** | 문제 파일을 읽다가 멈췄습니다 | 방금 넣은 CSV의 첫 줄과 저장 형식(UTF-8)을 확인하세요 |
| **deploy** | Pages가 안 켜져 있습니다 | 위의 **3번**을 하세요 |

**실패해도 지금 올라가 있는 게임은 그대로입니다.** 아이가 하던 것이 망가지지 않습니다 — 검사에서 멈추면 새 것이 나가지 않을 뿐입니다. 그게 검사를 배포 앞에 둔 이유입니다.

되돌리고 싶으면 저장소 위쪽 **Commits** 에서 잘 되던 시점을 찾아 되돌리면 됩니다. 아이 기록은 아이 아이패드에 있으니 여기서 뭘 해도 영향이 없습니다.

## 우리 집 게임은요?

**그대로 씁니다.** `시작하기.bat` 은 예전처럼 돕니다.

| | 우리 집 (`시작하기.bat`) | 인터넷 (Pages) |
|---|---|---|
| 기록이 있는 곳 | 집 PC의 `data/` 폴더 | 각 아이패드 브라우저 |
| 문제 고치면 | 새로고침하면 바로 | `git push` 하고 3~4분 |
| 자동 백업 | 하루 1회, 30일치 | 없음 — **가끔 내보내기 하세요** |
| 사진으로 단어 등록 (준비 중) | 됩니다 | 안 됩니다 |

둘 다 써도 됩니다. 다만 **기록이 따로 놉니다.** 집 PC에서 하던 것과 인터넷 주소에서 하던 것은 서로 다른 기록입니다. 하나로 합치려면 부모 화면의 **기록 내보내기 → 되돌리기** 를 쓰세요.

집에서 주로 하고 인터넷은 친구용으로 두는 쪽을 권합니다. 자동 백업이 있는 쪽이 안전합니다.
