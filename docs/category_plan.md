## 1. 구조

```
content/problems/
├─ 수학/
│   ├─ 1-3 나눗셈.csv
│   ├─ 1-4 곱셈.csv
│   └─ …
└─ 한국사/
    ├─ 1-1 구석기와 신석기.csv
    └─ …
```

| | 뜻 |
|---|---|
| **폴더 이름** | 과목 |
| **파일명 앞 `1-3`** | `1`학기 `3`단원. 학기 정보가 단원 번호에 그대로 들어갑니다 |
| **나머지** | 교과서 단원명 |

- `0-1` 처럼 쓰면 지난 학년 보충으로 맨 앞에 옵니다
- 정렬은 **자연 정렬**입니다. `1-10`이 `1-2` 뒤로 갑니다
- 폴더는 **한 겹만**. `수학/1학기/…` 는 안 읽습니다
- 폴더 밖의 파일은 과목 없이 지금처럼 동작하고 **진도 관리 대상이 아닙니다**

**파일명을 바꾸면 진도가 초기화됩니다.** 폴더를 옮기는 것은 괜찮습니다 — 팩 id가 파일명 슬러그라서입니다.

## 2. 진도는 부모가 정합니다

`/parent`의 **학습 진도**에서 과목마다 "여기까지 열기"를 고릅니다.

```
수학          여기까지 열기 [1-4 곱셈 ▼]  [저장]
 ✓ 1-3  나눗셈                문제 30개 · 완전히 외운 것 12
 ✓ 1-4  곱셈                  문제 30개 · 완전히 외운 것 0
 ┈┈┈┈ 여기부터는 아직 안 열렸습니다
 ·  1-5  길이와 시간            문제 30개
```

- **파일은 전부 만들어 두고, 학교 진도에 맞춰 하나씩 엽니다.** 뒤에 파일을 더 넣어도 안 열립니다
- 처음엔 **과목마다 첫 단원만** 열립니다
- 다 배운 단원은 켜둔 채로 두세요. 마스터한 문제는 가중치 0.8로 가끔만 나와 새 단원을 방해하지 않습니다
- 진도를 **내려도 됩니다.** 앞으로 그 문제가 안 나올 뿐, 진도·별·스티커·해금은 그대로입니다
- 개별 문제를 빼고 싶으면 **문제 켜고 끄기**를 쓰세요. 진도와 별개입니다

새 단원을 열면 아이 홈에 **"새로운 문제가 왔어!"** 가 뜹니다.

### 4.1 오답 보기가 이 과목의 전부입니다

글자 정답은 **같은 묶음의 다른 정답**이 오답 보기가 됩니다(`구현-현황.md` 2.2). 같은 묶음에 정답이 4종 미만이면 **그 문제는 게임에서 통째로 빠집니다.**

> 처음 계획은 여기서 스스로 모순이었습니다. 시대별로 파일을 나누면서 묶음을 `시대`로 두라고 했는데,
> 한 파일에 시대가 둘뿐이라 정답이 2종밖에 안 됩니다. 실제로 시험해보니 문제가 전부 빠졌습니다.

**두 가지로 풉니다.**

**1. 묶음을 답의 종류로 나눕니다.** `시대`가 아니라 `도구`·`살던 곳`·`유물`·`인물`·`싸움`처럼. 그러면 한 묶음에 답이 4~6종 모입니다.

```csv
돌을 깨뜨려 만든 도구를 뭐라고 할까?,뗀석기,,,,깨뜨려서 만든 거야,도구
돌을 갈아서 반들반들하게 만든 도구는?,간석기,,,,갈아서 만든 거야,도구
```
→ 보기: `주먹도끼` `간석기` `뗀석기` `갈판과 갈돌`

**2. 답이 적을 수밖에 없는 질문은 오답을 직접 적습니다.** 시대를 묻는 질문이 대표적입니다.

```csv
농사를 처음 짓기 시작한 시대는?,신석기,구석기,청동기,철기,한곳에 머물러야 농사를 지어,시대
```

같은 파일에 없는 시대(청동기·철기)를 오답으로 쓸 수 있어서, 오히려 자연스러운 보기가 됩니다.
