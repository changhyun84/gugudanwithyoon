# 국어 비슷한 말

묶음: 비슷한 말

- '기쁘다'와 비슷한 말은?  ->  즐겁다  // 웃음이 나는 기분이야
- '슬프다'와 비슷한 말은?  ->  서글프다
- '크다'와 비슷한 말은?  ->  거대하다  // 아주 클 때 쓰는 말이야
- '작다'와 비슷한 말은?  ->  조그맣다
- '빠르다'와 비슷한 말은?  ->  신속하다
- '아름답다'와 비슷한 말은?  ->  곱다
- '무섭다'와 비슷한 말은?  ->  두렵다
- '똑똑하다'와 비슷한 말은?  ->  영리하다  // 머리가 좋다는 뜻
- '이상하다'와 비슷한 말은?  ->  야릇하다
- '고맙다'와 비슷한 말은?  ->  감사하다
